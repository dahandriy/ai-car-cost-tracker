AI CAR COST TRACKER — КОРОТКИЙ ЧЕКЛИСТ

1. Распаковать архив.
2. Создать public GitHub repo: ai-car-cost-tracker.
3. Загрузить ВСЕ файлы проекта, включая .github и .gitignore.
4. Создать Supabase проект.
5. Применить 2 SQL migration в правильном порядке.
6. GitHub → Settings → Actions variables:
   VITE_SUPABASE_URL
   VITE_SUPABASE_PUBLISHABLE_KEY
7. GitHub → Settings → Pages → Source: GitHub Actions.
8. Supabase Auth → Site URL = GitHub Pages URL.
9. Supabase secrets: OPENAI_API_KEY, OPENAI_MODEL, AI_ALLOW_MOCK=false.
10. Deploy function: ai-assistant.
11. Проверить Free AI лимит = 5.
12. Stripe: создать AI Pro €9.99/month.
13. Supabase secrets: STRIPE_SECRET_KEY, STRIPE_PRO_PRICE_ID, APP_URL.
14. Deploy create-checkout-session.
15. Deploy stripe-webhook --no-verify-jwt.
16. Stripe webhook → checkout.session.completed, customer.subscription.updated, customer.subscription.deleted.
17. Supabase secret: STRIPE_WEBHOOK_SECRET.
18. Проверить регистрацию, CRUD, аналитику, AI, paywall, оплату, mobile, dark mode.
